# PRD-000. 기반 설계와 스캐폴딩

| 항목 | 값 |
|---|---|
| 상태 | **완료** |
| 기간 | 2026-08-10 ~ 2026-08-11 |
| 산출물 | ADR 7건, 빌드 골격, 공통 계층, V1 스키마 |

---

## 왜 이 사이클이 필요했나

과제 명세를 받았을 때 세 가지가 정해지지 않은 상태였다.

첫째, **이 과제가 무엇을 보려는 것인지** 몰랐다. 명세를 액면 그대로 읽으면 결제 API를 만들고 원장을 저장하는 CRUD다. 그러나 개요에 "정합성을 확인하기 위한 서버 시스템"이라는 문구가 있었고, 굳이 원장을 `PENDING`으로 **먼저** 저장하라는 요구가 붙어 있었다. 이 두 문구가 무엇을 의미하는지 판정해야 했다.

둘째, **어떤 판단이 평가 대상인지** 몰랐다. 명세가 "명시되지 않은 세부 정책은 지원자님의 판단에 따라 자유롭게 설계해 주세요"라고 재량을 열어두었다. 재량이 열려 있다는 것은 그 재량을 어떻게 썼는지가 평가된다는 뜻이다.

셋째, **무엇을 만들지 않을 것인지** 정해지지 않았다. 결제 시스템이라는 주제는 큐·캐시·분산락·이벤트를 자연스럽게 떠올리게 한다. 유사한 과거 과제에서 규모가 요구하지 않는 미들웨어를 도입해 스스로 최대 감점 요인으로 진단한 경험이 있었다.

## 무엇을 했나

### 도메인 조사

스위치원이 외환(FX) 전문 핀테크이고 선불 충전형 외화 지갑을 운영한다는 사실을 확인했다. 이것이 명세 해석의 기준이 됐다. 선불 지갑에서 잔액은 결제 성립의 **선행 조건**이지 사후 확인 대상이 아니다.

### 문제의식 도출

명세 시퀀스가 `외부 승인 → 잔액 확인` 순서인데, 선불 지갑에서 이 순서는 **외부는 성공하고 내부는 실패하는 미아 거래**를 만든다. Why so를 세 번 반복해 근본 원인이 **두 원장에 걸친 원자성 부재(dual-write)**임을 확인했다.

### 설계 판단 7건

| ADR | 결정 |
|---|---|
| [0001](../adr/0001-external-call-outside-transaction.md) | 외부 결제 호출은 트랜잭션 밖에서 수행한다 |
| [0002](../adr/0002-payment-no-as-idempotency-key.md) | 결제번호는 3rd party가 생성하고 멱등 키를 겸한다 |
| [0003](../adr/0003-atomic-balance-deduction.md) | 잔액 차감은 조건부 UPDATE로 원자화한다 |
| [0004](../adr/0004-timeout-is-indoubt.md) | 타임아웃은 실패가 아니라 결과 미상으로 다룬다 |
| [0005](../adr/0005-pre-check-balance-before-external-call.md) | 명세 시퀀스를 지키되 잔액 사전검증을 추가한다 |
| [0006](../adr/0006-single-server-no-middleware.md) | 단일 서버로 시작하고 미들웨어를 도입하지 않는다 |
| [0007](../adr/0007-mock-gateway-in-production.md) | 모의 게이트웨이를 운영 코드에 두고 프로파일로 전환한다 |

### 스캐폴딩

Java 25, Spring Boot 3.5.16, 인메모리 H2, Gradle wrapper. 공통 응답 규약과 전역 예외 처리, 상관관계 ID 필터, 게이트웨이 연동 경계, V1 스키마까지 구성했다.

## 이 사이클에서 뒤집힌 결정

진행 중 세 번 방향을 바꿨다. 기록해 둔다.

| 최초 결정 | 변경 | 계기 |
|---|---|---|
| MySQL + docker-compose | **인메모리 H2, 컨테이너 제거** | 명세 Tech Stack 절에 "In-Memory DB(H2) 또는 Local DB(SQLite)"가 명시되어 있었다. 초기 검토에서 이 문단을 읽지 않았다 |
| 모의 구현을 테스트 소스에 배치 | **운영 코드에 배치, 스텁 컨트롤러 제거** | 테스트 소스는 실행 산출물에 포함되지 않아 자족 실행이 불가능했다 |
| `idempotencyKey` 필드명 | **`merchantPaymentNo`** | 구현 메커니즘이 아니라 도메인 개념을 이름에 담는다. 부수적으로 타임아웃 후 조회가 가능해졌다 |
